# Task implementation summaries

Create `task-<n>-summary.md` only when the corresponding task is implemented and accepted. Include the implementation, changed or temporary resources, verification commands and results, dated evidence, and follow-up work. For the disposable proof, record sanitized run URLs, tested commit, outcomes, and cleanup confirmation.

Never include tokens, credentials, runtime secret values, private keys, or sensitive host details. Do not create implementation summaries before the work is done.
