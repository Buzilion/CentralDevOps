# Documentation Folder Roles

- **`design/`** — System design documents, such as architecture, data models, and technical decisions.
- **`notes/`** — Notable working material, including brainstorming, early ideas, and requirement drafts.
- **`prd/`** — The most mature, finalized requirements documents; treat these as the requirements baseline.
- **`specs/`** — Detailed, implementation-ready specifications and task breakdowns derived from the PRDs and generated design documents, intended to guide the implementation AI agent.
